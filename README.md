# 🐰 小一動物數學大比拼 🐯

## 簡介
這是一個為香港小一學生設計的互動式數學快速心算遊戲，結合可愛的動物角色和遊戲化的學習體驗。

## ✨ 功能特色

### 🎮 遊戲模式
- **單人練習**: 獨自挑戰10道題目
- **雙人對戰**: 與朋友進行實時競速比賽

### 📚 題型
- **純數字題**: 快速心算，包含進位加數和不借位減數
- **混合應用題**: 香港小一課程適用的應用題，涉及不同的量詞

### 🎨 視覺設計
- 🐰 8隻可愛動物可選（兔兔、貓咪、小狗、熊貓、鴨子、狐狸、猴子、老虎）
- 🎵 完整的音效系統（正確/錯誤/開始/勝利）
- 🏎️ 實時賽車進度條
- 🎯 邏輯合理的量詞搭配
- ✨ 流暢的動畫效果

## 📋 香港小一課程符合性

### 數字範圍
- **加法**: 1-99（可包含進位）
- **減法**: 1-99（不借位）

### 應用題量詞
#### 加法題
- 個（蘋果、餐盤）
- 張（貼紙、紙）
- 粒（糖果、彈珠）
- 本（書）
- 枝（鉛筆）
- 朵（花）
- 雙（襪子）

#### 減法題
- 塊（餅乾）
- 隻（小鳥）
- 個（氣球）
- 粒（波子）
- 包（果汁）
- 個（橡皮擦）
- 張（紙）

## 🚀 快速開始

### 前置要求
- Node.js (v14 或以上)
- npm 或 yarn

### 安裝步驟
```bash
# 克隆項目
git clone https://github.com/pomanworking-cmyk/math-racing-game.git
cd math-racing-game

# 安裝依賴
npm install

# 運行開發伺服器
npm start
```

### 構建生產版本
```bash
npm run build
```

## 📖 使用說明

1. **選擇遊戲模式**
   - 選擇純數字題或混合應用題
   - 選擇單人練習或雙人對戰

2. **選擇動物角色**
   - 從8隻可愛動物中選擇你的角色
   - 雙人模式下，每位玩家選擇不同的動物

3. **開始作答**
   - 仔細閱讀題目
   - 點擊正確答案
   - 完成10題即為獲勝

## 🎵 音效系統
- ✓ **正確答案**: 三個上升音符 (C5 → E5 → G5)
- ✗ **錯誤答案**: 兩個下降音符 (C5 → F4)
- 🎮 **遊戲開始**: 明亮的準備音效 (A4 → C#5 → E5)
- 🏆 **勝利**: 歡樂的勝利音樂

## 🎮 遊戲流程

### 菜單畫面
- 選擇題型：純數字題 或 混合應用題
- 選擇模式：單人練習 或 雙人對戰

### 動物選擇畫面
- 單人模式：選擇1隻動物
- 雙人模式：兩位玩家各選一隻不同的動物

### 遊戲畫面
- 顯示數學題目
- 三個選項供選擇
- 實時顯示進度條
- 音效反饋

### 結果畫面
- 顯示贏家
- 選項重新開始或返回菜單

## 📝 常見問題

### Q: 如何自定義題目?
A: 編輯 `App.jsx` 中的 `addContexts` 和 `subContexts` 陣列

### Q: 如何修改難度?
A: 調整 `generateQuestion()` 函數中的數字範圍

### Q: 如何添加更多動物?
A: 在 `ANIMALS` 陣列中添加新動物對象
